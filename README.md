# Hest.ia — versions

Téléchargements de **Hest.ia**, assistant de cabinet pour praticiens sur Mac (Apple Silicon, macOS 26).
Ce dépôt ne contient que les versions publiées ; l'app y vérifie l'existence d'une mise à jour.

## Installer

1. **Lisez le guide pas à pas : [INSTALLATION.md](INSTALLATION.md)** (20 minutes la première fois).
2. Téléchargez la dernière version : **[Releases → Latest](https://github.com/MaelCP/Hest.ia-releases/releases/latest)**,
   fichier `Hest.ia_…_aarch64.dmg` (pas besoin de compte GitHub).

En bref : ouvrez le `.dmg`, glissez Hest.ia sur Applications ; au premier lancement, Réglages Système →
Confidentialité et sécurité → « Ouvrir quand même ».

## Mettre à jour

Depuis l'app : **Réglages → Mises à jour → Mettre à jour**. Vos dossiers, votre signature et vos réglages
sont conservés.

Aucune donnée n'est envoyée à ce dépôt : il sert uniquement à télécharger l'app.
