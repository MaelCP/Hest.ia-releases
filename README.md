# Hest.ia — versions

Téléchargements de **Hest.ia**, assistant de cabinet pour praticiens sur Mac (Apple Silicon, macOS 26).
Ce dépôt ne contient que les versions publiées ; l'app y vérifie l'existence d'une mise à jour.

**Télécharger la dernière version :** [Releases → Latest](https://github.com/MaelCP/Hest.ia-releases/releases/latest)
(fichier `Hest.ia_…_aarch64.dmg`).

Installation pas à pas : ouvrez le `.dmg`, glissez Hest.ia sur Applications ; au premier lancement,
Réglages Système → Confidentialité et sécurité → « Ouvrir quand même ». Les mises à jour suivantes se font
depuis l'app : Réglages → Mises à jour.

Aucune donnée n'est envoyée à ce dépôt : il sert uniquement à télécharger l'app.
